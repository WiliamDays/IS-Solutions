# IS Solutions: Sistema de Gestão Comercial (MVP)

## Sobre o Projeto
O IS Solutions é um sistema de gestão comercial desenvolvido para otimizar e automatizar os processos de venda, integrando-os com outros setores, como logística e expedição. Com um foco total na experiência do usuário (UI), este projeto busca resolver um problema real do setor comercial: a falta de comunicação e a ineficiência causada por ela em um processo completo de vendas.

O foco da Versão 1.0 (MVP) é criar uma base sólida, funcional e que já entrega valor real. Ele foi projetado para demonstrar uma compreensão profunda das lógicas de negócio e das melhores práticas de desenvolvimento front-end.

Funcionalidades Principais (MVP)
Gestão de Vendas Simplificada: Um fluxo de criação de pedidos ágil, onde o vendedor pode registrar uma venda em poucos cliques. O sistema automaticamente dá baixa no estoque e alerta o usuário sobre a disponibilidade do produto.

Controle de Estoque Inteligente: O sistema permite o cadastro de novos produtos e a atualização da quantidade em estoque. A cada venda, o estoque é atualizado em tempo real, eliminando a necessidade de contagem manual diária.

Acompanhamento de Pedidos: Um painel intuitivo permite visualizar o status de cada pedido, facilitando o acompanhamento e a comunicação entre as equipes de vendas e logística.

Cadastro de Clientes: Uma ferramenta simples para o cadastro de informações de clientes, essencial para o histórico de vendas.

Design Responsivo: A aplicação é totalmente adaptada para funcionar em computadores, tablets e smartphones, garantindo acesso em qualquer lugar.

Tecnologias Utilizadas
Este projeto foi desenvolvido utilizando as seguintes tecnologias:

Front-end: React.js

Estilização: SASS

Persistência de Dados: Para esta versão MVP, o projeto utiliza o localStorage do navegador para persistir os dados, simulando a comunicação com uma API e permitindo um desenvolvimento ágil.

Como Usar
Clone este repositório para sua máquina local.

Instale as dependências: npm install (ou yarn install).

Inicie a aplicação: npm start (ou yarn start).

Abra seu navegador e acesse http://localhost:3000.

Desafios e Próximos Passos (Versão 2.0+)
O desenvolvimento deste MVP trouxe desafios importantes, como a implementação de um gerenciamento de estado eficiente para o controle de estoque e a criação de uma interface de usuário intuitiva.

Para as próximas versões, os planos incluem:

Autenticação de usuários: Implementação de um sistema de login e perfis de acesso.

Integração com uma API: Migração do localStorage para um backend real com banco de dados (ex: Node.js + Express, Python + Django).

Módulo de Relatórios: Adição de gráficos e dashboards para análise de vendas e desempenho.
